# Legacy Spike Scripts

This directory keeps one-off investigation scripts that are useful for
historical reproducibility but are not production entrypoints and are not
included in the Windows operator ZIP.

Use `scripts/run_weekly_target_year_discovery.py` and
`scripts/target_year_acquisition_plan.py` for current rolling target-year
operations. Files here may contain FY2026 / Reiwa 8 wording because they
preserve the original investigation context.
