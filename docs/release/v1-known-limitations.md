# v1 Known Limitations

Updated: 2026-07-11

This file records current Linux/Web v1 limitations. It does not weaken the
release gates in `docs/release/linux-web-v1-gates.md`.

## Release State

- Current conclusion is `NOT_READY` until the served-app, intranet reachability,
  backup/restore, and operational audit evidence are complete.
- Green unit tests prove source behavior, not that business computers can reach
  the Venus service.
- The Web service remains bound to `127.0.0.1`; an approved reverse proxy or
  tunnel is required for intranet access.

## Product Scope

- v1 targets vocational schools (`専門学校`) first.
- Users provide or confirm the correct official PDF; nationwide automatic
  discovery is support-only and is not a release blocker.
- SQLite enforces one writer. Real-time concurrent editing, task claiming,
  row-level locks, SSO, and role-based permissions are not yet implemented.
- The file-backed Web review MVP is not yet connected to the authoritative
  `manual_action_log`/JSONL outbox; this remains a release blocker, not an
  accepted audit substitute.
- Copilot/OneDrive output is comparison input, not an automatically trusted
  source and not a live API integration.
- PostgreSQL, FastAPI/React, and full multi-user authorization require a later
  architecture decision.

## Data Quality

- OCR is an exception path. Missing image-PDF runtime support must route to
  manual review rather than silently producing trusted data.
- Low-confidence, mismatched-school, non-target, old-year, and unresolved
  program-change rows must not enter final Excel output.
- Excel is generated by the service; users must not treat independently edited
  workbook copies as the system of record.

## Operations

- Venus deployment is restricted to `/home/junming/EIDP`, including `.venv`,
  data, caches, logs, and exports.
- The repository currently defines the application process, not a system-wide
  service, firewall rule, SSO integration, or backup scheduler.
- Image/OCR-lane browser E2E and exact sample assertions remain release work.
