# Owner Decision Briefs

This directory contains short owner-facing decision briefs. They are not release
approval by themselves.

Use them to decide which release path is acceptable. Use the current release
status, evidence bundle, release gates, Windows evidence, and owner sign-off
artifacts to approve or reject an actual release.

Current owner decisions:

- `publication-lag.md`
- `ocr-scope.md`

Rules:

- The owner decision can be short.
- The release evidence cannot be short.
- The agent may prepare these briefs, but must not approve them.
- No owner decision may allow unconfirmed rows into final Excel output.
- `READY`, `RC_ONLY`, and `NOT_READY` are the only release conclusions.
