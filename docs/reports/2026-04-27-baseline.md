## 周次測定ルーチン

毎週月曜:
```bash
eidp report coverage --json > docs/reports/weekly/$(date +%Y-%m-%d)-coverage.json
eidp report extraction --fy 2026 --json > docs/reports/weekly/$(date +%Y-%m-%d)-extraction.json
eidp report gaps --kind pdf --json > docs/reports/weekly/$(date +%Y-%m-%d)-gaps-pdf.json
```

これで Sprint 進捗を「印象」ではなく「数字 vs baseline」で評価できる。
