## 周次測定ルーチン

毎週月曜（FY2026 を固定するため `--fiscal-year 2026` / `--fy 2026` を必須）:
```bash
DATE=$(date +%Y-%m-%d)
mkdir -p docs/reports/weekly
eidp report coverage --fiscal-year 2026 --json \
  > docs/reports/weekly/${DATE}-coverage.json
eidp report extraction --fy 2026 --json \
  > docs/reports/weekly/${DATE}-extraction.json
eidp report gaps --kind pdf --fy 2026 --json \
  > docs/reports/weekly/${DATE}-gaps-pdf.json
eidp report gaps --kind url --json \
  > docs/reports/weekly/${DATE}-gaps-url.json
```

これで Sprint 進捗を「印象」ではなく「数字 vs baseline」で評価できる。
FY を明示することで R8 / R9 越境時にも復現可能。
