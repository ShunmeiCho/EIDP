## 2. 跨 Sheet 校名差异 — 対象比率 661 行 + 学科別 247 行未匹配

`採録状況` sheet 中的校名与 `対象比率`/`学科別` sheet 中的校名存在微小差异
（空格、全角/半角、法人名不一致等），导致 lookup 失败。

**根本原因**: importer 使用 exact string match `(prefecture, corporation_name, school_name)`

**解决方案**:
- Step 4 后重新导入时使用 NFKC 标准化 lookup
- 或在 Step 6 Review Queue 中补充 school_alias 后重新关联

**影响**: 约 6.6% 的 対象比率 数据和 2.5% 的学科別数据未导入

## 4. MEXT 目標列表差距 — 118 校

MEXT 対象機関リスト中有 2,071 所専門学校，但其中 118 所不在我们的 DB 中。

**可能原因**:
- 新设校（2025-2026 年新增）
- 我们的 Excel 数据库未收录的学校
- 命名差异导致的假阴性

**操作**: Step 4 对账时需要确认这些学校是否需要加入 DB
