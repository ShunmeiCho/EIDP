False-reject worksheet rules
----------------------------
The worksheet is an RCA input, not release approval and not Excel proof.
Fill only decision/reviewer/reviewed_at/notes. Do not edit row context such as
audit_row_id, bucket, school fields, URLs, anchor text, or review questions.

Allowed decisions:
  false_reject
  correct_reject
  needs_operator_review

Every completed row must include reviewer and an ISO reviewed_at timestamp.
false_reject and needs_operator_review rows must include notes citing the
official evidence or the unresolved human-review reason.

Developer validation is run from current main, or from a v542+ package carrying
the same verifier integration, after return. The v542 package proves the
verifier is available; it does not prove the returned worksheet is complete.
The returned CSV is checked through scripts\verify_stage6_return.py with
--false-reject-evidence-zip, --false-reject-review-csv, and
--false-reject-sample-size 12.
