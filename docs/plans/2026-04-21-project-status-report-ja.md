## 1. プロジェクトの目的

日本の専門学校約2,400校の在籍学生データを自動収集することを目指しています。データソースは、各校が公式サイトに公開している **高等教育の修学支援新制度 機関要件確認申請書（様式第2号）** PDFファイルです。

現行では、6月から8月にかけて担当者が手作業で各校のPDFをダウンロードし、内容を読み取り、Excelに転記しています。本プロジェクトはこの工程を自動化することを目的とします。

**成功基準**: 手作業の工数を50〜70%削減すること。

## 5. 完了した主要作業

### 5.1 技術基盤の構築（完了）

- **データベース**: PostgreSQL 17（Venus GPUサーバー上）
- **OCRシステム**: PaddleOCR PP-OCRv5 + PaddlePaddle 3.0 GPU版（RTX 6000 Ada × 2基）
- **開発環境**: uv仮想環境（Python 3.12）
- **デプロイメント**: Venus単一サーバー運用（DB + OCR + パイプライン一体化）
- **納品形態**: 学校のIT担当者が `docker-compose up` で一括起動可能

1. **日本語OCR精度の改善**

2. **Codexとの9ラウンド横断レビュー**
   - 合計52件の問題を発見し、51件を修正（1件は誤検出）

3. **セキュリティインシデント対応（4/17）**

## 6. 現在直面している主要課題

### 6.1 🔴 最大のボトルネック：PDF自動発見の上限（Step 8）

**現状**: URLが取得できた1,827校のうち、クローラーが有効なPDFを発見できたのは87校（4.8%）のみ。8分間の盲目的クロールで成果ゼロ。

**根本原因**:
1. 対象PDFの多くが `/wp-content/uploads/...` のような深さ3階層以上のディレクトリに配置されており、クローラーが到達しにくい
2. 大法人（例：学校法人大原学園182校、三幸学園100校）は様式第2号を**公開していない可能性**、または学校単位ではなく法人単位で公開している
3. 各校の公開場所とファイル名規則が異なり、汎用的なルールで推定できない

**人手作業でも同様の上限**: 2024年度の完全採録は943校（45.6%）、部分採録804校。すべての学校が公開しているわけではない。

### 6.2 🟡 OCR解析成功率23%（Step 9）

**現状**: ダウンロード成功87件のうち、完全な解析・取り込みができたのは20件。

**失敗の内訳**:
- parse_failed（解析失敗）: 16件（非標準フォーマット、異常なページ構造）
- school_mismatch（学校不一致）: 12件（PDFと学校が一致しない。主に法人共有PDF）

### 6.3 🟡 人手の知見を伝達する仕組みの欠如

**現状**: 担当者チームが過去に採録した943校のURL知識（ファイル配置パターン）が、システムに入力されていない。

**影響**: AIは盲目的クロールしかできず、人間が蓄積した位置特定の知見を活用できていない。

### 6.4 🟢 残作業（アーキテクチャ関連）

- setup.shワンクリック導入スクリプトが未作成（学校IT担当への納品が困難）
- cron自動実行未設定（毎週の更新に手動操作が必要）
- OCRフローの回帰テストが未整備
- 323校のreconcile候補が手動確認待ち（大原52校、三幸30校等）

## 8. 今後の推奨アプローチ（並行して3路線）

### Path A: 標的型深度クロール（昨年のURLが取得できる場合）

**工数**: 1日
**期待成果**: 500〜800校カバー

昨年のURLをアンカーに今年のパスを予測（年度置換、親ディレクトリ一覧、フォールバッククロール）。盲目的全サイトクロールより30〜100倍効率的。

### Path B: 現状の受容と納品整備

**工数**: 3〜5日
**内容**:
- setup.sh + READMEの整備（学校IT担当向けワンクリック導入）
- 毎週cron自動実行の設定（差分更新）
- 人手介入フローの整備（レビューUI + 手動PDFアップロード）
- 回帰テストの整備

**成果**: 24校の2025年最新データ + 2,068校の2024年過去データを含むMVPの納品。

### Path C: 人機ハイブリッド（推奨）

**工数**: 1〜2週間
**内容**:
- Streamlit review UIにPDFアップロード + URL送信機能を追加
- 担当者チームが毎日20〜30件のURLを送信
- システムが自動取り込み
- 2ヶ月以内に800〜1,200校カバーの見込み
