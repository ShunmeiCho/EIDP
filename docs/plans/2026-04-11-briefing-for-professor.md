# 在校生人数データ自動収集システム — ご報告

## 概要

現在手作業で行っている「各大学・専門学校の在校生人数データの収集・転記作業」を自動化するシステムの設計を進めています。本資料では、調査結果・技術方針・ご確認いただきたい事項をまとめます。

---

## 1. 現状の確認

いただいたExcelファイル（専門学校分）を分析した結果は以下のとおりです。

| 項目 | 数値 |
|------|------|
| 専門学校の対象校数 | 2,212校 |
| 対象法人数 | 1,442法人 |
| 対象都道府県 | 47 |
| 学科別データ行数 | 約9,761件 |
| 2025年度の採録済み（〇） | 943校（43%） |
| 2025年度の部分採録（△） | 804校（36%） |

※ 大学約700校分のデータについては、別途サンプルデータのご提供をお願いいたします。

## 2. 自動化の方針

### やること

ご依頼いただいた4つの工程を、以下のように自動化します。

| ご依頼の工程 | 自動化内容 |
|-------------|----------|
| 工程1：PDFの収集 | 各校のウェブサイトからPDFを自動で発見・ダウンロード |
| 工程2：年度チェック | 前年度データとの自動比較により令和8年度版かを判定 |
| 工程3：データ転記 | PDFからデータを自動抽出し、データベースに格納 |
| 工程4：競合校レポート更新 | 週次で自動集計し、Excelファイルを生成 |

### 段階的アプローチ

一度に全自動化を目指すのではなく、段階的に自動化率を高めます。

| 段階 | 内容 | 期間 | 自動化率（見込み） |
|------|------|------|----------|
| 第0段階 | 200校のサンプルで検証 | 2週間 | — |
| 第1段階 | 各校のURL特定＋PDF発見 | 2〜3週間 | 70〜85% |
| 第2段階 | テキスト型PDFのデータ抽出 | 2〜3週間 | 60〜80% |
| 第3段階 | 画像型PDF対応＋学科変更対応 | 継続 | +10〜15% |
| 第4段階 | 週次の定期更新運用 | 1週間 | — |

**6月の公開開始までに第2段階まで完了を目指します。**

### 人手が残る部分

完全自動化が難しい箇所は、システム内の「確認キュー」に入り、担当者が画面上で確認・修正します。

- 自動で判定できなかった学校のURL確認（推定220〜440校）
- 画像のみのPDFの確認
- 学科の新設・廃止・改称・統合の対応（推定100〜300件）

ご指示の通り、学科変更が発生した場合はシステム側でエラーを出し、人力で対応する方針とします。

**推定作業量：6〜8月の期間中、週2〜4時間程度**

### NotebookLM等との比較

ご提案いただいたNotebookLM等にPDFを投入して自然言語で問い合わせる方法も検討しました。結論として、今回のケースでは構造化パイプライン（自動抽出＋データベース）の方が適しています。

| 観点 | NotebookLM等 | 構造化パイプライン（今回の方式） |
|------|-------------|--------------------------|
| 一回限りの調査 | 向いている | オーバースペック |
| 毎年の繰り返し作業 | 毎回手動投入が必要 | 一度構築すれば自動で回る |
| 週次の増分更新 | 困難 | 自動で差分検知・更新可能 |
| 数値の正確性 | 回答にブレが出る可能性 | ルールベースで安定 |
| 監査・追跡 | 難しい | 全データの出典PDFを記録 |

ただし、NotebookLMは「過去データの横断的な分析・質問応答」には有効です。データベース構築後の補助ツールとして活用する余地があります。

## 3. 決定事項一覧（全件確定済み）

全ての確認事項について方針を決定しました。

| 項目 | 決定内容 |
|------|--------|
| 学科変更時の取り扱い | エラーを出力し、人力で対応 |
| 学校の識別方法 | 文部科学省「学校コード」を採用（91%自動照合済み） |
| 大学の取り扱い | v1では専門学校に集中（大学のPDFフォーマットが異なることを確認済み） |
| 対象校の範囲 | 155校を自動収集から除外（マスタデータには保持）。対象校数：2,057校 |
| 競合分類 | 15分野カテゴリで確定。85%自動分類、15%確認キュー。判定結果は蓄積し次年度自動適用 |
| 運用体制 | 開発者自身が全作業を担当。macOSで開発、学内Linux PCに展開 |

## 4. 想定されるリスク

| リスク | 影響 | 対策 |
|--------|------|------|
| 学校サイトがPDFを遅れて公開 | 収集漏れ | 週次で自動再チェック |
| 画像のみのPDFが多い場合 | OCR精度低下 | 該当校は確認キューで人手対応 |
| 学校サイトのアクセス制限 | PDF取得不可 | ブラウザ自動化で対応 |
| 学科の大幅な改組 | 自動対応困難 | エラー出力＋人力対応（ご指示済み） |
